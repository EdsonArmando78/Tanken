# Pendientes de integración

Las fases 2–7 están implementadas en Java y Views XML con Material 3 Expressive.
Se retiraron calculadora, saludo, vídeo y WebView de ejemplo. Ayuda y Acerca de
muestran información local; Temporizadores conserva sus cuatro trabajadores y cola,
ahora con View Binding y ListAdapter. No quedan demostraciones pendientes de decisión.

Queda la fase 8: instrumentadas y recorrido físico, evidencias y reporte académico.
Comprobar actualización conservando datos, navegación/rotación con formularios,
teclado/fuentes grandes/tema oscuro, sensores, avisos y reinicio, importación válida
e inválida, enlaces sin red y restablecimiento. Los permisos del sistema se conservan.
Las instrumentadas se compilaron; aún no se ejecutaron en dispositivo.
